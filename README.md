# DevOps Mini Projects

A collection of hands-on DevOps mini projects demonstrating Docker, Kubernetes, Terraform, Linux Automation, CI/CD, and Infrastructure as Code concepts.

## 📌 Projects Included

### 1. Docker Compose Web Application
A simple multi-container web application deployed using Docker Compose.

**Technologies Used**
- Docker
- Docker Compose
- HTML
- GitHub Actions

**Features**
- Multi-container deployment
- Container orchestration using Docker Compose
- Automated CI workflow

---

### 2. Kubernetes Pod Scaling
A Kubernetes-based application deployment with service exposure and scaling capabilities.

**Technologies Used**
- Kubernetes
- Docker
- YAML
- GitHub Actions

**Features**
- Deployment management
- Service configuration
- Pod scaling and monitoring
- Automated deployment workflow

---

### 3. Linux System Administration Automation
Collection of Linux automation scripts for system administration tasks.

**Technologies Used**
- Bash Scripting
- Linux

**Features**
- Directory structure automation
- System health monitoring
- Administrative task automation

---

### 4. Terraform Hands-On
Infrastructure as Code project using Terraform.

**Technologies Used**
- Terraform
- AWS/Cloud Infrastructure
- Checkov
- TFLint

**Features**
- Infrastructure provisioning
- Security and compliance validation
- Infrastructure configuration management

---

### 5. Dockerized To-Do Application
A containerized Flask-based To-Do application.

**Technologies Used**
- Python
- Flask
- Docker

**Features**
- Task management system
- Containerized deployment
- Lightweight web application

---

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/devops-mini-projects.git
cd devops-mini-projects
```

### Prerequisites

- Docker
- Docker Compose
- Kubernetes (Minikube or Kind)
- Terraform
- Git
- Linux Environment
